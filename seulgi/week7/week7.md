## API

API: 다른 사람들이 내 컴퓨터에 있는 데이터에 접근할 수 있도록 만들어둔 기능

인터넷: 컴퓨터끼리 대화할 수 있도록 만든 연결망

IP주소: 컴퓨터가 인터넷에 연결되면 다른 컴퓨터에서 접근할 수 있도록 주소를 할당받음

도메인: 문자열로 된 주소

웹: 인터넷에 연결된 사용자들이 서로 정보를 공유할 수 있는 공간

클라이언트: 요청하는 컴퓨터

서버: 응답하는 컴퓨터

프로토콜: 컴퓨터끼리 정보를 주고받는 방법 (HTTP)

HTTP: 웹에서 컴퓨터끼리 대화할 때 따르는 규칙

파라미터: 요청을 보낼 때 같이 보내는 데이터

## 동기&비동기

동기: 하나의 일이 끝난 뒤 다음 일을 하는 방식

비동기: 하나의 일이 끝나기 전에 동시에 다른 일을 하는 방식

비동기 방식으로 동작하는 경우, 응답을 받기전에 결과를 보여주려고 하며 에러가 발생하기 때문에 이러한 상황에서는 동기방식으로 동작하는 것이 좋음.

개발시 비동기 방식으로 작동하는 상황들

- 네트워크 요청하여 데이터 받아오기

- 파일 읽기/쓰기

- 데이터베이스 쓰기

HTTP 요청과 같이 실행하는데 시간이 걸리는 코드들은 기본적으로 비동기방식으로 동작하기 때문에 이러한 문제를 해결하기 위해서는 동기 방식으로 바꾸어 실행하는 것이 필요.

```dart
void main() {
  print("1");
  await Future.delayed(Duration(seconds: 1), () {
    print("2");
  });
  print("3");
}
```

async/await을 사용하는 함수는 반환값을 미래에 해당타입을 반환한다는 의미로 Future<반환타입> 형태로 표시해줌

```dart
Future<String> getFood() async {
  await Future.delayed(Duration(seconds: 1), () {
    print("cooking...");
  });

  return "pizza";
}
```
